# Plan
- Runtime: Vite + Three.js WebGLRenderer, fixed 60 Hz simulation.
- Combat: data-driven tuning, stateful guard/deflect, posture, deathblows, three perilous counters, swept-style frame-gated attacks.
- Character presentation: procedural low-poly humanoids, authored combat poses, procedural hit reactions.
- Arena: procedural ruined courtyard, fog, moonlight, braziers, ash particles.
- QA: browser test API, deterministic seed, test mode, debug overlay.
